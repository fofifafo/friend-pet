## 프롬프트 본문

너는 Windows 데스크톱 앱 개발자다. 아래 요구사항에 맞는 프로그램을 단계별로 개발해라.

### 1. 프로젝트 개요

"친구 데스크톱 펫" 프로그램을 만든다.
화면 위를 돌아다니는 데스크톱 캐릭터는 이미 있는 장르다. 여기에 "친구"를 더하는 것이 핵심이다.

- 내 캐릭터가 바탕화면 위를 돌아다닌다.
- 친구의 캐릭터도 내 화면에 함께 등장한다.
- 친구가 지금 무엇을 하는지(코딩, 게임, 영상 시청, 자리 비움 등) 친구 캐릭터의 행동과 모션으로 표현된다.
- 친구 캐릭터를 클릭하면 상태를 자세히 볼 수 있는 작은 패널이 뜬다.
- 채팅을 보내면 상대방 화면에서 내 캐릭터 머리 위에 말풍선으로 표시된다.

### 2. 확정된 조건

- 대상 OS: Windows 10/11 우선. 다른 OS는 고려하지 않는다.
- 비용: 개발 비용 0원을 목표로 한다. 유료 서비스나 유료 에셋을 쓰지 않는다.
- 사용 규모: 소수 친구 그룹(10명 이하)을 가정한다.
- 활동 공유 수준: 창 제목이나 URL 원본은 절대 서버로 보내지 않는다. 클라이언트에서 "코딩 / 게임 / 영상 / 문서 / 브라우징 / 자리 비움 / 알 수 없음" 같은 카테고리로 분류한 뒤 카테고리만 전송한다.
- 캐릭터 스타일: 픽셀 아트. 1차 개발은 itch.io 또는 OpenGameArt의 CC0 에셋을 쓴다.
- 서버 방식: Supabase 무료 티어 (Realtime + Auth 사용)

### 3. 기술 스택

- 클라이언트: Electron + TypeScript. 투명하고 테두리 없는 항상 위(always-on-top) 창에 캐릭터를 렌더링한다. 클릭 통과(click-through)를 지원하되 캐릭터 영역은 클릭 가능해야 한다.
- 활동 감지: Windows API로 현재 활성 창의 프로세스 이름과 창 제목을 읽고, 로컬에서 카테고리로 변환한다. 원본은 저장도 전송도 하지 않는다.
- 서버: 실시간 상태 동기화와 채팅 전달. WebSocket 또는 Supabase Realtime을 사용한다.
- 인증: 친구 그룹 내부용이므로 초대 코드 방식으로 간단히 처리한다.
- 배포: electron-builder로 설치 파일을 만들고 GitHub Releases에 올린다. 코드 서명은 하지 않는다.

### 4. 개발 순서

반드시 아래 순서대로 진행하고, 각 단계가 실제로 실행되는 것을 확인한 뒤 다음 단계로 넘어가라.

1. **혼자 돌아다니는 캐릭터**
   투명 창 위에서 캐릭터가 걷기, 멈추기, 앉기 애니메이션을 반복하며 화면 하단을 돌아다닌다. 드래그로 옮길 수 있고, 트레이 아이콘으로 종료할 수 있다.
2. **내 활동 감지**
   활성 창을 읽어 카테고리로 분류하고, 내 캐릭터가 그 카테고리에 맞는 모션(키보드 두드리기, 게임패드 들기, 눕기 등)을 보인다.
3. **서버 연결과 상태 공유**
   내 카테고리를 서버로 보내고, 같은 그룹 친구들의 캐릭터가 내 화면에 나타나 각자의 상태 모션을 보인다. 친구가 오프라인이면 캐릭터가 사라지거나 잠든 모습으로 바뀐다.
4. **클릭 상세 패널**
   친구 캐릭터를 클릭하면 이름, 현재 상태, 마지막 활동 시각이 작은 패널로 뜬다.
5. **말풍선 채팅**
   패널에서 메시지를 입력해 보내면 상대방 화면에서 내 캐릭터 위에 말풍선이 몇 초간 떠 있다가 사라진다. 최근 메시지는 간단한 로그로 볼 수 있다.

### 5. 지켜야 할 규칙

- 각 단계를 시작하기 전에 무엇을 만들지 한두 줄로 설명하고 시작한다.
- 외부 라이브러리를 추가할 때는 이유를 짧게 적는다.
- 프라이버시 규칙(원본 창 제목과 URL 비전송)을 어기는 코드는 작성하지 않는다.
- 설정 파일에 상태 공유 끄기(투명 모드) 옵션을 넣는다.
- 완료한 단계와 남은 단계를 매번 요약해서 보고한다.
- 에러가 나면 숨기지 말고 원문을 보여 주고 원인을 설명한다.
